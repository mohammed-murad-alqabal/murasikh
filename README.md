## 📖 عن المشروع

**مُرَسِّخ** هو MVP تجريبي لرفيق روحي ذكي، يرافق المستخدم في حياته اليومية ويحلل النص وبعض إشارات السياق لتقديم توجيه قرآني وروحي. بعض القدرات متعددة الوسائط والمنصات ما تزال تجريبية أو مؤجلة.

### 🎯 الأهداف

- **ترسيخ القيم الإسلامية** - تعزيز مكارم الأخلاق والسلوك الإيجابي
- **الدعم النفسي** - توفير الدعم الروحي والمعنوي في الأوقات الصعبة
- **التوجيه اللحظي** - تقديم نصائح مناسبة في الوقت المناسب
- **السهولة واليسر** - واجهة بسيطة وسهلة الاستخدام

### ✨ الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🎯 **تحليل المشاعر** | فهم الحالة العاطفية للمستخدم من النص |
| 📚 **قاعدة معرفة قرآنية** | 6,236 آية مع التفاسير |
| 🔍 **البحث الدلالي** | RAG للدقة الشرعية بدون Hallucination |
| 📱 **دعم دون اتصال** | cache وfallback محدودان، وليس تحليلاً محلياً كاملاً |
| 🎚️ **الاستجابة المدرجة** | مراعاة الحالة النفسية للمستخدم |
| 🔒 **الخصوصية** | جلسات قابلة للإبطال، حذف حساب خادمي، وتخزين Hive مشفّر؛ حذف المزود/النسخ الاحتياطية يخضع لسياسة الاحتفاظ |

## 🚀 البدء السريع

### المتطلبات

| البرنامج | الإصدار |
|----------|---------|
| Python | 3.11+ |
| Flutter | 3.16+ |
| Docker | 24+ |
| PostgreSQL | 15+ |

### التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/mohammed-murad-alqabal/murasikh.git
cd murasikh

# 2. إعداد Backend
cd backend
python -m venv venv
source venv/bin/activate  # Linux/macOS
pip install -r requirements.txt

# 3. إعداد قاعدة البيانات
docker-compose up -d db redis
alembic upgrade head

# 4. تشغيل الخادم
uvicorn app.main:app --reload
```

### التحقق

```bash
curl http://localhost:8000/health
# {"status": "ok"}
curl http://localhost:8000/health/ready
# readiness: PostgreSQL, Redis, and Chroma
```

## 🛠️ التقنيات المستخدمة

### Backend

| التقنية | الاستخدام |
|---------|----------|
| **FastAPI** | إطار العمل الرئيسي |
| **PostgreSQL** | قاعدة البيانات العلائقية |
| **Chroma** | قاعدة البيانات المتجهية |
| **Redis** | التخزين المؤقت والجلسات |
| **SQLAlchemy** | ORM |
| **Alembic** | تهجير قاعدة البيانات |

### AI & ML

| التقنية | الاستخدام |
|---------|----------|
| **paraphrase-multilingual-MiniLM-L12-v2** | Embeddings للعربية |
| **Google Gemini** | تحليل المشاعر والتوليد |
| **Sentence Transformers** | البحث الدلالي |

> **ملاحظة حول سياسة المحتوى (ContentPolicy.QURAN_ONLY):** في نسخة الـ MVP الحالية، تم تثبيت سياسة الاعتماد على القرآن الكريم حصراً. ملفات الحديث النبوي المضمنة في المستودع غير مستخدمة فعلياً في مجموعة ChromaDB الخاصة بالمحرك، ولن يتم استرجاعها كجزء من المواساة.

### Frontend

| التقنية | الاستخدام |
|---------|----------|
| **Flutter** | إطار العمل الرئيسي |
| **Hive** | قاعدة البيانات المحلية |
| **BLoC** | إدارة الحالة |
| **package:http** | طلبات HTTP |
