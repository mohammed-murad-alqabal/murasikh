# اختبارات أداء البحث الدلالي وRAG

هذه الاختبارات تقيس الميزانية الزمنية لمسار البحث والترتيب وطبقة RAG المحلية دون استدعاء Gemini أو تحميل نموذج لغوي ثقيل. تستخدم اختبارات البحث نموذجًا ومخزنًا وهميين لعزل تكلفة الخوارزمية عن الشبكة وقرص Chroma، بينما تستخدم اختبارات RAG التصفية المحلية وقالب التراجع.

## التشغيل

```bash
cd backend
python -m pytest tests/performance -m performance -q
```

تشغّل CI هذه الاختبارات في خطوة مستقلة باسم `Performance smoke tests (semantic search and RAG)`.

## الميزانيات الحالية

تُقاس النسبة المئوية 95 من زمن التنفيذ، والحد الحالي هو 20ms لكل عملية في بيئة CI بالنسبة إلى الترتيب الهجين، وتنسيق البحث الوهمي، واختيار الآية المحلي، وقالب التراجع. هذه ليست بديلًا عن اختبار إنتاج كامل؛ عند توفر بيئة Chroma ونموذج التضمين ينبغي إجراء اختبار تحميل منفصل خارج CI باستخدام بيانات مماثلة للإنتاج.
