## 🔧 إعداد بيئة التطوير

### 1. استنساخ المستودع

```bash
# استنساخ المشروع
git clone https://github.com/murassikh/murassikh.git
cd murassikh

# إنشاء فرع للميزة الجديدة
git checkout -b feature/my-feature
```

### 2. إعداد Backend

```bash
# الانتقال لمجلد Backend
cd backend

# إنشاء بيئة افتراضية
python -m venv venv

# تفعيل البيئة الافتراضية
source venv/bin/activate  # Linux/macOS
# أو
.\venv\Scripts\activate   # Windows

# تثبيت التبعيات
pip install -r requirements.txt

# نسخ ملف البيئة
cp .env.example .env

# تعديل ملف .env بالمعلومات الصحيحة
# GEMINI_API_KEY=your_key_here
# DATABASE_URL=postgresql://...
# REDIS_URL=redis://...
```

### 3. إعداد قاعدة البيانات

```bash
# تشغيل PostgreSQL و Redis عبر Docker
docker-compose up -d db redis

# تشغيل الـ Migrations
alembic upgrade head

# (اختياري) ملء البيانات التجريبية
python scripts/seed_data.py
```

### 4. تشغيل الخادم

```bash
# تشغيل خادم التطوير
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# الخادم متاح على:
# http://localhost:8000
# http://localhost:8000/docs (Swagger UI)
```

### 5. إعداد Frontend (Flutter)

```bash
# الانتقال لمجلد Frontend
cd ../frontend

# تثبيت التبعيات
flutter pub get

# تشغيل التطبيق (محاكي أو جهاز حقيقي)
flutter run

# أو للويب
flutter run -d chrome
```

## 🐳 استخدام Docker (الطريقة السهلة)

```bash
# من جذر المشروع
cd docker

# بناء وتشغيل جميع الخدمات
docker-compose up -d

# عرض السجلات
docker-compose logs -f

# إيقاف الخدمات
docker-compose down
```

الخدمات المتاحة:
- API: http://localhost:8000
- PostgreSQL: localhost:5432
- Redis: localhost:6379
- Chroma: ./chroma_db

## ✅ التحقق من الإعداد

### التحقق من Backend

```bash
# اختبار صحة API
curl http://localhost:8000/api/v1/health

# يجب أن يعيد:
# {"status": "healthy", "version": "0.1.0"}
```

### التحقق من قاعدة البيانات

```bash
# الاتصال بـ PostgreSQL
docker exec -it murassikh-db psql -U user -d murassikh

# التحقق من الجداول
\dt

# الخروج
\q
```

### التحقق من Redis

```bash
# اختبار Redis
docker exec -it murassikh-redis redis-cli ping

# يجب أن يعيد: PONG
```

## 🔑 متغيرات البيئة

### Backend (.env)

```bash
# Application
APP_NAME="Murassikh API"
APP_VERSION=0.1.0
DEBUG=True

# Database
DATABASE_URL=postgresql://user:password@localhost:5432/murassikh

# Redis
REDIS_URL=redis://localhost:6379/0

# AI & ML
GEMINI_API_KEY=your_gemini_api_key
EMBEDDING_MODEL=GATE-AraBERT-v1

# Security
SECRET_KEY=your_secret_key_here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# CORS
ALLOWED_ORIGINS=["http://localhost:3000", "http://localhost:8000"]
```
