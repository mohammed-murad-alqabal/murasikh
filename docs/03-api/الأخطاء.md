# ❌ رموز الأخطاء

توثيق شامل لجميع رموز ورسائل الأخطاء في API.

---

## 📊 رموز HTTP

| الرمز | المعنى | متى يُستخدم |
|-------|--------|-------------|
| `200` | OK | نجاح العملية |
| `201` | Created | إنشاء مورد جديد |
| `400` | Bad Request | طلب غير صالح أو بيانات ناقصة |
| `401` | Unauthorized | غير مصادق أو token منتهي |
| `403` | Forbidden | غير مسموح بالوصول |
| `404` | Not Found | المورد غير موجود |
| `409` | Conflict | تعارض (مثل مستخدم موجود) |
| `422` | Unprocessable Entity | خطأ في التحقق من البيانات |
| `429` | Too Many Requests | تجاوز حد الطلبات |
| `500` | Internal Server Error | خطأ داخلي في الخادم |
| `503` | Service Unavailable | الخدمة غير متاحة مؤقتاً |

## 🏷️ رموز الأخطاء التفصيلية

### أخطاء المصادقة (AUTH_*)

| الرمز | HTTP | الرسالة |
|-------|------|---------|
| `AUTH_INVALID_CREDENTIALS` | 401 | البريد الإلكتروني أو كلمة المرور غير صحيحة |
| `AUTH_TOKEN_EXPIRED` | 401 | انتهت صلاحية الجلسة، يرجى تسجيل الدخول مجدداً |
| `AUTH_TOKEN_INVALID` | 401 | Token غير صالح |
| `AUTH_UNAUTHORIZED` | 401 | يجب تسجيل الدخول أولاً |
| `AUTH_USER_EXISTS` | 409 | المستخدم موجود مسبقاً |

### أخطاء التحقق (VALIDATION_*)

| الرمز | HTTP | الرسالة |
|-------|------|---------|
| `VALIDATION_ERROR` | 400 | بيانات غير صالحة |
| `EMPTY_TEXT` | 400 | النص المدخل فارغ |
| `TEXT_TOO_SHORT` | 400 | النص يجب أن يكون على الأقل 3 أحرف |
| `TEXT_TOO_LONG` | 400 | النص يتجاوز الحد المسموح (1000 حرف) |
| `INVALID_EMAIL` | 400 | البريد الإلكتروني غير صالح |
| `WEAK_PASSWORD` | 400 | كلمة المرور ضعيفة جداً |

### أخطاء التوصية (RECOMMENDATION_*)

| الرمز | HTTP | الرسالة |
|-------|------|---------|
| `RECOMMENDATION_NOT_FOUND` | 404 | لم يتم العثور على توصية مناسبة |
| `RECOMMENDATION_SERVICE_ERROR` | 503 | خدمة التوصيات غير متاحة مؤقتاً |

### أخطاء عامة (GENERAL_*)

| الرمز | HTTP | الرسالة |
|-------|------|---------|
| `NOT_FOUND` | 404 | المورد غير موجود |
| `RATE_LIMIT_EXCEEDED` | 429 | تجاوزت عدد الطلبات المسموحة، حاول لاحقاً |
| `INTERNAL_ERROR` | 500 | خطأ داخلي، يرجى المحاولة لاحقاً |
| `SERVICE_UNAVAILABLE` | 503 | الخدمة غير متاحة مؤقتاً |

## 📥 تنسيق الرد

```json

  "error": {
    "code": "EMPTY_TEXT",
    "message": "النص المدخل فارغ"
  }

```

## 💡 معالجة الأخطاء

### في JavaScript/TypeScript

```javascript
try {
  const response = await api.post('/recommend', { text });
  // معالجة النجاح
} catch (error) {
  if (error.response) {
    const { code, message } = error.response.data.error;
    
    switch (code) {
      case 'AUTH_TOKEN_EXPIRED':
        // إعادة تسجيل الدخول
        break;
      case 'RATE_LIMIT_EXCEEDED':
        // انتظار وإعادة المحاولة
        break;
      default:
        // عرض رسالة الخطأ
        console.error(message);
    }
  }
}
```

### في Flutter (Dart)

```dart
try {
  final response = await dio.post('/recommend', data: {'text': text});
  // معالجة النجاح
} on DioException catch (e) {
  if (e.response != null) {
    final error = e.response!.data['error'];
    final code = error['code'];
    
    switch (code) {
      case 'AUTH_TOKEN_EXPIRED':
        // إعادة تسجيل الدخول
        break;
      default:
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text(error['message'])),
        );
    }
  }
}
```

## 🔄 إعادة المحاولة

### متى يعاد المحاولة

| الخطأ | إعادة المحاولة؟ | الانتظار |
|-------|----------------|----------|
| 400 | ❌ لا | - |
| 401 | ❌ لا (أعد المصادقة) | - |
| 429 | ✅ نعم | انتظر `Retry-After` header |
| 500 | ✅ نعم | Exponential backoff |
| 503 | ✅ نعم | انتظر 30 ثانية |

### Exponential Backoff

```python
import time
import random

def retry_with_backoff(func, max_retries=3):
    for attempt in range(max_retries):
        try:
            return func()
        except (ServerError, ServiceUnavailable) as e:
            if attempt == max_retries - 1:
                raise
            wait_time = (2 ** attempt) + random.random()
            time.sleep(wait_time)
```
