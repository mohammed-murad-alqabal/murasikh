# 💬 Endpoint: التغذية الراجعة

توثيق endpoint إرسال تغذية راجعة على التوصيات.

---

## 📋 المعلومات

| البند | القيمة |
|-------|--------|
| **Endpoint** | `/feedback` |
| **الطريقة** | `POST` |
| **المصادقة** | مطلوبة |
| **الوصف** | إرسال تقييم للتوصية المقدمة |

---

## 📤 الطلب

### Headers

```
Content-Type: application/json
Authorization: Bearer {token}
```

### Body

```json
{
  "interaction_id": 12345,
  "is_positive": true,
  "comment": "التوصية كانت مناسبة جداً لحالتي"
}
```

### المعاملات

| المعامل | النوع | مطلوب | الوصف |
|---------|------|-------|-------|
| `interaction_id` | int | ✅ | معرف التفاعل من endpoint التوصية |
| `is_positive` | bool | ✅ | true = 👍 مفيد، false = 👎 غير مفيد |
| `comment` | string | ❌ | تعليق اختياري (500 حرف كحد أقصى) |

---

## 📥 الردود

### نجاح (200)

```json
{
  "success": true,
  "message": "شكراً لملاحظاتك!"
}
```

### interaction_id غير موجود (404)

```json
{
  "success": false,
  "error": {
    "code": "INTERACTION_NOT_FOUND",
    "message": "التفاعل غير موجود"
  }
}
```

---

## 💡 أمثلة

### تقييم إيجابي

```bash
curl -X POST "https://api.murassikh.com/api/v1/feedback" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"interaction_id": 12345, "is_positive": true}'
```

### تقييم سلبي مع تعليق

```bash
curl -X POST "https://api.murassikh.com/api/v1/feedback" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "interaction_id": 12345,
    "is_positive": false,
    "comment": "التوصية لم تكن مناسبة لحالتي"
  }'
```

---

## 📊 استخدام التغذية الراجعة

تُستخدم التغذية الراجعة لـ:

1. **تحسين التوصيات** - التعلم من تفضيلات المستخدم
2. **ضمان الجودة** - تحديد التوصيات غير المناسبة
3. **الإحصائيات** - قياس فعالية النظام

---

## 🔒 الخصوصية

- التغذية الراجعة مجهولة الهوية في التحليلات
- لا تُشارك مع أطراف ثالثة
- تُخزن بشكل آمن ومشفر
