# Endpoint التغذية الراجعة

## المعلومات

| البند | القيمة |
|---|---|
| Endpoint | `/api/v1/history/feedback` |
| الطريقة | `POST` |
| المصادقة | مطلوبة |
| الوصف | حفظ تقييم تفاعل يخص المستخدم الحالي |

## الطلب

```http
POST /api/v1/history/feedback
Content-Type: application/json
Authorization: Bearer <token>
```

```json
{
  "id": 12345,
  "feedback": 1
}
```

القيم المسموحة لـ`feedback` هي `1` للتقييم الإيجابي، `-1` للتقييم السلبي، و`0` للمحايد. الحقل `id` هو معرف التفاعل في سجل المستخدم الحالي.

## الرد

```json
{
  "status": "success"
}
```

## الأخطاء

- `401`: المستخدم غير مصادق.
- `404`: التفاعل غير موجود أو لا يخص المستخدم الحالي.
- `422`: قيمة `id` أو `feedback` غير صالحة.
- `429`: تجاوز الحد.

## مثال

```bash
curl -X POST "https://api.murassikh.com/api/v1/history/feedback" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"id":12345,"feedback":1}'
```

لا تستخدم الصيغة القديمة `interaction_id` و`is_positive` في العملاء الجدد. كما لا ينبغي حذف تقييم pending من الجهاز إلا بعد استلام استجابة 2xx من الخادم.
