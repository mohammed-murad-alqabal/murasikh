# 🎯 Endpoint: التوصية

توثيق endpoint الحصول على توصية دينية.

---

## 📋 المعلومات

| البند | القيمة |
|-------|--------|
| **Endpoint** | `/recommend` |
| **الطريقة** | `POST` |
| **المصادقة** | اختيارية |
| **الوصف** | الحصول على توصية دينية مناسبة |

---

## 📤 الطلب

### Headers

```
Content-Type: application/json
Authorization: Bearer {token}  # اختياري
```

### Body

```json
{
  "text": "أشعر بالقلق والتوتر من المستقبل",
  "emotion_hint": "قلق"  // اختياري
}
```

### المعاملات

| المعامل | النوع | مطلوب | الوصف |
|---------|------|-------|-------|
| `text` | string | ✅ | نص المستخدم |
| `emotion_hint` | string | ❌ | تلميح الحالة العاطفية |

---

## 📥 الردود

### نجاح (200)

```json
{
  "emotion": "قلق",
  "confidence": 0.85,
  "content_type": "verse",
  "arabic_text": "أَلَا بِذِكْرِ اللَّهِ تَطْمَئِنُّ الْقُلُوبُ",
  "translation": "ألا بذكر الله تطمئن القلوب",
  "tafsir": "ذكر الله تعالى سبب لطمأنينة القلوب...",
  "source": "سورة الرعد: 28",
  "tier": "full",
  "interaction_id": 12345
}
```

### استجابة Minimal (Tier 1)

```json
{
  "emotion": "غضب",
  "confidence": 0.95,
  "content_type": "symbol",
  "arabic_text": "💚",
  "translation": "",
  "tafsir": "",
  "source": "",
  "tier": "minimal",
  "interaction_id": 12346
}
```

---

## ❌ الأخطاء

### نص فارغ (400)

```json
{
  "success": false,
  "error": {
    "code": "EMPTY_TEXT",
    "message": "النص المدخل فارغ"
  }
}
```

### نص قصير جداً (400)

```json
{
  "success": false,
  "error": {
    "code": "TEXT_TOO_SHORT",
    "message": "النص يجب أن يكون على الأقل 3 أحرف"
  }
}
```

## 💡 أمثلة

### cURL

```bash
curl -X POST "https://api.murassikh.com/api/v1/recommend" \
  -H "Content-Type: application/json" \
  -d '{"text": "أشعر بالحزن"}'
```

### Python

```python
import requests

response = requests.post(
    "https://api.murassikh.com/api/v1/recommend",
    json={"text": "أشعر بالحزن"}
)

data = response.json()
print(data['arabic_text'])
```

### Flutter (Dart)

```dart
final response = await dio.post(
  '/recommend',
  data: {'text': 'أشعر بالحزن'},
);

final recommendation = Recommendation.fromJson(response.data);
```

## 📊 الحقول

| الحقل | النوع | الوصف |
|-------|------|-------|
| `emotion` | string | الحالة العاطفية المكتشفة |
| `confidence` | float | ثقة التحليل (0-1) |
| `content_type` | string | نوع المحتوى (`verse` أو `verse` أو `symbol`) |
| `arabic_text` | string | النص العربي |
| `translation` | string | الترجمة |
| `tafsir` | string | التفسير |
| `source` | string | المصدر |
| `tier` | string | مستوى الاستجابة (`minimal` أو `moderate` أو `full`) |
| `interaction_id` | int | معرف التفاعل (للتغذية الراجعة) |
