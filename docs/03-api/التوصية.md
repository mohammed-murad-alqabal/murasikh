# Endpoint التوصية النصية

## المعلومات

| البند | القيمة |
|---|---|
| Endpoint | `/api/v1/analyze` |
| الطريقة | `POST` |
| المصادقة | اختيارية؛ المصادقة مطلوبة لحفظ السجل والتخصيص الكامل |
| الحالة | العقد الرسمي الحالي |

## الطلب

```http
POST /api/v1/analyze
Content-Type: application/json
Authorization: Bearer <token> # اختياري
```

```json
{
  "text": "أشعر بالقلق والتوتر من المستقبل",
  "user_context": {
    "age": 30,
    "gender": "ذكر"
  }
}
```

`text` مطلوب وطوله بين حرفين و1000 حرف. `user_context` اختياري ويخضع للنموذج المشترك في Backend.

## الرد الناجح

```json
{
  "emotion": "قلق",
  "confidence": 0.85,
  "tier": "moderate",
  "message": "...",
  "delayed_message": null,
  "source": "سورة الرعد: ٢٨",
  "tafsir": "...",
  "interaction_id": 12345
}
```

الحقول الأساسية هي `emotion` و`confidence` و`tier` و`message`. وقد تكون `source` و`tafsir` و`delayed_message` و`interaction_id` فارغة بحسب الحالة والمصادقة.

لا تستخدم الحقول القديمة `arabic_text` أو `content_type` أو `translation` في العملاء الجدد.

## أمثلة

```bash
curl -X POST "https://api.murassikh.com/api/v1/analyze" \
  -H "Content-Type: application/json" \
  -d '{"text":"أشعر بالحزن"}'
```

```dart
final response = await http.post(
  Uri.parse('$baseUrl/analyze'),
  headers: headers,
  body: jsonEncode({'text': text}),
);
```

## الأخطاء

- `401`: رمز غير صالح عند استخدام مصادقة غير صحيحة.
- `422`: النص أو السياق لا يطابقان النموذج.
- `429`: تجاوز الحد.
- `503`: فشل dependency أو عدم جاهزية الخدمة.

## ملاحظة نطاق المحتوى

مسار التوصية الحالي قرآن-only من حيث الاسترجاع. يجب أن يكون أي محتوى مسترجع من نوع `verse`، ولا تعد خدمات الأحاديث جزءاً من هذا العقد.
