# 🔐 Endpoint: المصادقة

توثيق endpoints المصادقة والتحقق من الهوية.

---

## 📋 Endpoints

| Endpoint | الطريقة | الوصف |
|----------|---------|-------|
| `/auth/register` | POST | تسجيل مستخدم جديد |
| `/auth/login` | POST | تسجيل الدخول |
| `/auth/logout` | POST | تسجيل الخروج |
| `/auth/refresh` | POST | تجديد Token |
| `/auth/me` | GET | معلومات المستخدم الحالي |

---

## 📝 تسجيل مستخدم جديد

### الطلب

```bash
POST /auth/register
Content-Type: application/json

{
  "username": "ahmed123",
  "email": "ahmed@example.com",
  "password": "SecurePass123!"
}
```

### المعاملات

| المعامل | النوع | مطلوب | القيود |
|---------|------|-------|--------|
| `username` | string | ✅ | 3-50 حرف، أحرف وأرقام فقط |
| `email` | string | ✅ | بريد إلكتروني صالح |
| `password` | string | ✅ | 8+ أحرف، حرف كبير، رقم، رمز |

### الرد الناجح (201)

```json
{
  "success": true,
  "message": "تم إنشاء الحساب بنجاح",
  "data": {
    "user": {
      "id": 1,
      "username": "ahmed123",
      "email": "ahmed@example.com",
      "created_at": "2026-09-11T10:00:00Z"
    },
    "tokens": {
      "access_token": "eyJhbGciOiJIUzI1NiIs...",
      "refresh_token": "eyJhbGciOiJIUzI1NiIs...",
      "token_type": "bearer",
      "expires_in": 1800
    }
  }
}
```

## ❌ الأخطاء

### بيانات غير صالحة (400)

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "البريد الإلكتروني غير صالح"
  }
}
```

### مستخدم موجود (409)

```json
{
  "success": false,
  "error": {
    "code": "USER_EXISTS",
    "message": "البريد الإلكتروني مستخدم مسبقاً"
  }
}
```

### بيانات خاطئة (401)

```json
{
  "success": false,
  "error": {
    "code": "INVALID_CREDENTIALS",
    "message": "البريد الإلكتروني أو كلمة المرور غير صحيحة"
  }
}
```

## 🔒 أمان كلمة المرور

### المتطلبات

- 8 أحرف على الأقل
- حرف كبير واحد على الأقل
- رقم واحد على الأقل
- رمز خاص واحد على الأقل (!@#$%^&*)

### التشفير

- bcrypt مع salt rounds = 12
