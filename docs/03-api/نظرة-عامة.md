# 🌐 نظرة عامة على API

توثيق واجهات برمجة التطبيقات (API) لمشروع مُرَسِّخ.

---

## 📋 المعلومات الأساسية

| البند | القيمة |
|-------|--------|
| **Base URL** | `https://api.murassikh.com/api/v1` |
| **الإصدار** | v1 |
| **التنسيق** | JSON |
| **المصادقة** | JWT Bearer Token |
| **اللغة** | العربية (RTL) |

---

## 🔗 الـ Endpoints المتاحة

| الطريقة | Endpoint | الوصف |
|---------|----------|-------|
| `POST` | `/auth/register` | تسجيل مستخدم جديد |
| `POST` | `/auth/login` | تسجيل الدخول |
| `POST` | `/recommend` | الحصول على توصية |
| `POST` | `/feedback` | إرسال تغذية راجعة |
| `GET` | `/history` | عرض سجل التفاعلات |
| `GET` | `/health` | فحص صحة الخدمة |

---

## 🔐 المصادقة

### الحصول على Token

```bash
POST /auth/login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "secure_password"
}
```

### الرد

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 1800
}
```

### استخدام Token

```bash
GET /history
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

---

## 📤 تنسيق الطلبات

### Headers

```
Content-Type: application/json
Accept: application/json
Authorization: Bearer {token}  # للمسارات المحمية
Accept-Language: ar
```

---

## 📥 تنسيق الردود

### نجاح

```json
{
  "success": true,
  "data": { ... },
  "message": "تمت العملية بنجاح"
}
```

### خطأ

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "النص المدخل فارغ",
    "details": { ... }
  }
}
```

---

## ⚡ حدود الاستخدام (Rate Limiting)

| الخطة | الحد |
|-------|------|
| مجهول | 50 طلب/ساعة |
| مسجل | 500 طلب/ساعة |
| Premium | غير محدود |

### Headers في الرد

```
X-RateLimit-Limit: 500
X-RateLimit-Remaining: 495
X-RateLimit-Reset: 1699200000
```

---

## ❌ رموز الأخطاء

| الكود | الحالة | المعنى |
|-------|--------|--------|
| `400` | Bad Request | طلب غير صالح |
| `401` | Unauthorized | غير مصادق |
| `403` | Forbidden | غير مسموح |
| `404` | Not Found | غير موجود |
| `422` | Validation Error | خطأ في البيانات |
| `429` | Too Many Requests | تجاوز الحد |
| `500` | Internal Server Error | خطأ في الخادم |
