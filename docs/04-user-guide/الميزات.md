## 🎯 الميزات الأساسية

### 1. التوصية الذكية

```
وصف مشاعرك ← تحليل الحالة ← آية قرآنية مناسبة
```

**كيف تعمل:**
1. تكتب أو تصف مشاعرك
2. النظام يحلل حالتك العاطفية
3. يختار آية قرآنية مناسب
4. يقدمه مع تفسير ميسر

---

### 2. الاختيار السريع

اختر حالتك مباشرة من الأيقونات:

| الأيقونة | الحالة | أمثلة التوصيات |
|----------|--------|----------------|
| 😠 | غضب | آيات كظم الغيظ |
| 😢 | حزن | آيات الصبر |
| 😰 | قلق | آيات الطمأنينة |
| 😊 | فرح | آيات الشكر |
| ✈️ | سفر | أدعية السفر |
| 📚 | دراسة | آيات العلم |

---

### 3. العمل بدون إنترنت

**المحتوى المتاحoffline:**
- 6,000+ آية
- حصرياً
- التفاسير الميسرة

**المزايا:**
- لا حاجة للاتصال الدائم
- استجابة فورية (< 100ms)
- خصوصية كاملة للبيانات

---

### 4. الاستجابة المدرجة

التطبيق يراعي حالتك النفسية:

| شدة الانفعال | نوع الاستجابة |
|--------------|---------------|
| شديد جداً | رمز لطيف فقط (🌸) |
| متوسط | نص مختصر |
| خفيف | نص كامل مع تفسير |
