## حدود أمنية مهمة

- **Argon2id** هو خوارزمية كلمات المرور الحالية؛ لا تستخدم وثائق bcrypt التاريخية.
- تسجيل الدخول يستخدم `username/password` عبر OAuth2 form، ويعيد tokens مباشرة دون غلاف `success/data`.
- `POST /auth/logout` يبطل access token الحالي حسب `session_version`، وليس refresh token فقط.
- `DELETE /auth/account` يحذف بيانات التطبيق الخادمية المملوكة للحساب. لا يدّعي حذف سجلات مزود الذكاء الاصطناعي أو النسخ الاحتياطية الخارجية قبل تعريف سياسة retention وتنفيذها.
- عزل صناديق Hive ليس بديلاً عن التشفير؛ Phase 1 يستخدم `HiveAesCipher` ومفتاحاً في التخزين الآمن، ويحذف المفتاح عند purge.
- لا تُرسل `age` أو `gender` أو `facial_emotion` أو `biometric_stress` إلى مزود AI دون `sensitive_context_consent: true`.
- لا يجوز وصف الصوت بأنه ASR أو وصف الوجه بأنه تشخيص نفسي.

## بوابة التحقق

لا تصنف المنظومة Production Ready قبل حفظ الأدلة التالية مرتبطة بـcommit وبيئة:

1. logout ثم طلب خاص بالـaccess token القديم يعيد `401` فوراً.
2. إنشاء حساب وتفاعل ورد مؤجل وتقييم، ثم حذف الحساب والتحقق من عدم بقاء السجلات.
3. فحص ملفات Hive بعد التخزين وعدم ظهور النص الخام، ثم التحقق من الحذف ومفتاح التشفير.
4. التقاط payload إلى AI مع وبدون الموافقة والتأكد من تقليل البيانات.
5. backup مشفر وrestore drill مع تحقق دلالي وRPO/RTO.
6. اختبار secrets وTLS وrate limit وcorrupted cache وnetwork failure.
