## 🐳 Docker Services

### docker-compose.yml

```yaml
version: '3.8'

services:
  # API Server
  api:
    build:
      context: .
      dockerfile: docker/Dockerfile
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/murassikh
      - REDIS_URL=redis://redis:6379
      - GEMINI_API_KEY=${GEMINI_API_KEY}
    depends_on:
      - db
      - redis
    volumes:
      - ./app:/app/app
      - chroma_data:/app/chroma_db
    deploy:
      replicas: 2
      resources:
        limits:
          cpus: '2'
          memory: 4G

  # PostgreSQL
  db:
    image: postgres:15-alpine
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=pass
      - POSTGRES_DB=murassikh
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  # Redis
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

  # Nginx (Production)
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./ssl:/etc/nginx/ssl
    depends_on:
      - api

volumes:
  postgres_data:
  redis_data:
  chroma_data:
```

## 🌐 الشبكة

| HTTPS | 443 | main entry point |

| Redis | 6379 | internal only |

### SSL/TLS

- **Provider**: Let's Encrypt
- **Renewal**: Auto-renewal via certbot
- **Protocols**: TLS 1.2, TLS 1.3
