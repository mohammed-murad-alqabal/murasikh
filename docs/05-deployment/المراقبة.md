## 📈 المقاييس (Metrics) (مخطط مستقبلي)

### API Metrics

| المقياس | الوصف | الهدف |
|---------|-------|-------|
| `http_requests_total` | عدد الطلبات | - |
| `http_request_duration_seconds` | زمن الاستجابة | < 2s (p95) |
| `http_requests_in_flight` | الطلبات النشطة | < 100 |
| `api_errors_total` | عدد الأخطاء | < 1% |

### Database Metrics

| المقياس | الوصف | الهدف |
|---------|-------|-------|
| `pg_connections` | الاتصالات النشطة | < 80% pool |
| `pg_query_duration_seconds` | زمن الاستعلام | < 100ms |
| `pg_replication_lag` | تأخر النسخ | < 1s |

### Redis Metrics

| المقياس | الوصف | الهدف |
|---------|-------|-------|
| `redis_memory_used_bytes` | الذاكرة المستخدمة | < 80% |
| `redis_cache_hit_ratio` | نسبة الإصابة | > 80% |
| `redis_connected_clients` | العملاء المتصلين | < 100 |

### Application Metrics

| المقياس | الوصف | الهدف |
|---------|-------|-------|
| `recommendation_requests_total` | طلبات التوصية | - |
| `recommendation_latency_seconds` | زمن التوصية | < 2s |
| `embedding_generation_seconds` | زمن الـ Embedding | < 500ms |
| `emotion_analysis_seconds` | زمن التحليل | < 300ms |

## 🚨 التنبيهات (Alerts) (مخطط مستقبلي)

### Critical Alerts

| التنبيه | الشرط | الإجراء |
|---------|-------|--------|
| `APIDown` | لا استجابة لمدة 1 دقيقة | إيميل + SMS |
| `DatabaseDown` | لا اتصال | إيميل + SMS |
| `HighErrorRate` | أخطاء > 5% لمدة 5 دقائق | إيميل |
| `OutOfMemory` | RAM > 95% | إيميل + Scale Up |

### Warning Alerts

| التنبيه | الشرط | الإجراء |
|---------|-------|--------|
| `HighLatency` | p95 > 3s لمدة 5 دقائق | إيميل |
| `LowCacheHitRate` | hit rate < 70% لمدة 10 دقائق | إيميل |
| `HighDBLoad` | connections > 70% pool | إيميل |

## 📝 Logging

### Log Levels

| المستوى | الاستخدام |
|---------|----------|
| `DEBUG` | تطوير فقط |
| `INFO` | أحداث عادية |
| `WARNING` | مشاكل محتملة |
| `ERROR` | أخطاء تحتاج معالجة |
| `CRITICAL` | أخطاء جوهرية |

### Log Format

```json
{
  "timestamp": "2026-09-11T10:00:00Z",
  "level": "INFO",
  "service": "api",
  "request_id": "abc123",
  "user_id": 1,
  "message": "Recommendation generated",
  "duration_ms": 150,
  "emotion": "حزن",
  "confidence": 0.85
}
```

### Log Aggregation

- **Tool**: Loki or ELK Stack
- **Retention**: 30 days
- **Search**: Grafana Explore

## 🔧 التكوين (مخطط مستقبلي)

### Prometheus Rules

```yaml
# prometheus/rules.yml
groups:
  - name: api
    rules:
      - alert: HighLatency
        expr: histogram_quantile(0.95, http_request_duration_seconds_bucket) > 3
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High API latency"
          description: "p95 latency is {{ $value }}s"
```

### Alertmanager Config

```yaml
# alertmanager/config.yml
global:
  resolve_timeout: 5m

route:
  receiver: 'team-email'
  group_by: ['alertname']
  group_wait: 30s
  group_interval: 5m

receivers:
  - name: 'team-email'
    email_configs:
      - to: 'team@murassikh.com'
        from: 'alerts@murassikh.com'
        smarthost: 'smtp.example.com:587'
```
