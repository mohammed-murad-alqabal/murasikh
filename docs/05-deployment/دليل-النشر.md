# 🚀 دليل النشر

دليل خطوة بخطوة لنشر مشروع مُرَسِّخ.

---

## 📋 المتطلبات

### أدوات مطلوبة

- Docker 24+
- Docker Compose 2.20+
- Git
- SSL Certificate (Let's Encrypt)

### معلومات مطلوبة

- Domain name
- SSL certificate
- API keys (Gemini)
- Database credentials

---

## 🔧 إعداد الخادم

### 1. تحديث النظام

```bash
# Ubuntu 22.04
sudo apt update && sudo apt upgrade -y
sudo apt install -y docker.io docker-compose-v2 git nginx certbot python3-certbot-nginx
```

### 2. إعداد Docker

```bash
sudo usermod -aG docker $USER
newgrp docker
```

### 3. استنساخ المشروع

```bash
git clone https://github.com/murassikh/murassikh.git
cd murassikh
```

---

## ⚙️ التكوين

### 1. إنشاء ملف .env

```bash
cp .env.example .env.production
nano .env.production
```

### 2. تكوين SSL

```bash
sudo certbot --nginx -d api.murassikh.com
```

### 3. تكوين Nginx

```nginx
# /etc/nginx/sites-available/murassikh

server {
    listen 80;
    server_name api.murassikh.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.murassikh.com;

    ssl_certificate /etc/letsencrypt/live/api.murassikh.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.murassikh.com/privkey.pem;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 🐳 النشر بالـ Docker

### 1. بناء الصور

```bash
docker compose -f docker-compose.prod.yml build
```

### 2. تشغيل الـ Migrations

```bash
docker compose -f docker-compose.prod.yml run --rm api alembic upgrade head
```

### 3. ملء البيانات الأولية

```bash
docker compose -f docker-compose.prod.yml run --rm api python scripts/seed_data.py
```

### 4. تشغيل الخدمات

```bash
docker compose -f docker-compose.prod.yml up -d
```

### 5. التحقق

```bash
# التحقق من الخدمات
docker compose -f docker-compose.prod.yml ps

# التحقق من الـ API
curl https://api.murassikh.com/api/v1/health
```

## 📊 النشر مع Kubernetes (اختياري)

### Deployment YAML

```yaml
# k8s/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: murassikh-api
spec:
  replicas: 3
  selector:
    matchLabels:
      app: murassikh-api
  template:
    metadata:
      labels:
        app: murassikh-api
    spec:
      containers:
      - name: api
        image: murassikh/api:latest
        ports:
        - containerPort: 8000
        env:
        - name: DATABASE_URL
          valueFrom:
            secretKeyRef:
              name: murassikh-secrets
              key: database-url
        resources:
          limits:
            memory: "4Gi"
            cpu: "2"
---
apiVersion: v1
kind: Service
metadata:
  name: murassikh-api-service
spec:
  selector:
    app: murassikh-api
  ports:
  - port: 80
    targetPort: 8000
  type: LoadBalancer
```
