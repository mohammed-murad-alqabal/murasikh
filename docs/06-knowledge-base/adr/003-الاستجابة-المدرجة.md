# ADR-003: نظام الاستجابة المدرجة (Tiered Response)

## الحالة
مقبول ✅

## التاريخ
2026-09-11

## السياق

عندما يكون المستخدم في حالة انفعال شديد، قد يكون التدخل المباشر والكامل مزعجاً. وثائق المشروع حددت مطلب "الاستجابات المؤجلة" (FR-8).

### المشكلة

- التدخل الفوري قد يزيد من توتر المستخدم
- إخفاء التدخل تماماً يفوت فرصة المساعدة
- كل مستخدم يختلف في استجابته

## القرار

اعتماد **نظام الاستجابة المدرجة** مع ثلاثة مستويات:

### المستويات

| المستوى | الشدة | الاستجابة |
|---------|-------|-----------|
| **Tier 1: Minimal** | > 0.9 | رمز فقط (🌸 💚 🕊️) |
| **Tier 2: Moderate** | 0.7-0.9 | نص مختصر بدون تفسير |
| **Tier 3: Full** | < 0.7 | النص كاملاً مع التفسير |

### مثال عملي

**سيناريو: مستخدم غاضب جداً**

```
المدخل: "أشعر بغضب شديد جداً"
التحليل: غضب، ثقة 0.95
القرار: Tier 1 (Minimal)
المخرج الفوري: 💚
المخرج المؤجل (بعد 30 دقيقة): آية كظم الغيظ مع التفسير
```

## العواقب

### إيجابية ✅
- تقليل الإزعاج للمستخدم
- تقديم المساعدة بالوقت المناسب
- احترام الحالة النفسية

### سلبية ⚠️
- تعقيد إضافي في المنطق
- صعوبة قياس الفعالية

## المراجع

- وثيقة المشروع: FR-8 (الاستجابات المؤجلة)
- وثيقة المخاطر: التعارض "التنبيه اللحظي مقابل عدم الاستفزاز"
