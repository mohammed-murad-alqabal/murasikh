# 📖 قاموس المصطلحات

قاموس شامل للمصطلحات المستخدمة في مشروع مُرَسِّخ.

---

## 💻 المصطلحات التقنية

| المصطلح | التعريف |
|---------|---------|
| **ADR** | Architecture Decision Record - سجل قرار معماري |
| **API** | Application Programming Interface - واجهة برمجة التطبيقات |
| **Backend** | الخلفية - جزء التطبيق الذي يعمل على الخادم |
| **BLoC** | Business Logic Component - نمط إدارة الحالة في Flutter |
| **Cache** | ذاكرة مؤقتة لتسريع الوصول للبيانات |
| **CI/CD** | Continuous Integration/Continuous Deployment - التكامل والنشر المستمر |
| **Chroma DB** | قاعدة بيانات متجهية للبحث الدلالي |
| **Edge Computing** | معالجة البيانات على جهاز المستخدم |
| **Embedding** | تمثيل رقمي للنص يلتقط المعنى الدلالي |
| **FastAPI** | إطار عمل Python لبناء APIs |
| **Frontend** | الواجهة الأمامية التي يراها المستخدم |
| **GATE-AraBERT** | نموذج تمثيل نصي عربي متقدم |
| **Hallucination** | توليد محتوى غير صحيح من قبل النموذج |
| **Hive** | قاعدة بيانات محلية لتطبيقات Flutter |
| **JWT** | JSON Web Token - معيار لنقل المعلومات بشكل آمن |
| **LLM** | Large Language Model - نموذج لغوي كبير |
| **MVP** | Minimum Viable Product - المنتج الأدنى القابل للتطبيق |
| **NLP** | Natural Language Processing - معالجة اللغة الطبيعية |
| **Offline-First** | بنية تعتمد على البيانات المحلية كمصدر أساسي |
| **PostgreSQL** | نظام إدارة قواعد بيانات علائقية |
| **Prompt Engineering** | هندسة الأوامر لنماذج اللغة |
| **RAG** | Retrieval-Augmented Generation - التوليد المعزز بالاسترجاع |
| **Redis** | مخزن بيانات في الذاكرة للذاكرة المؤقتة |
| **Semantic Search** | البحث بالمعنى وليس بالكلمات الحرفية |
| **Vector Database** | قاعدة بيانات متخصصة في المتجهات |

## 🕌 المصطلحات الشرعية

| المصطلح | التعريف |
|---------|---------|
| **الآية** | جملة أو عبارة من القرآن الكريم |
| **الحديث** | ما نُسب إلى النبي محمد ﷺ من قول أو فعل |
| **الحديث الصحيح** | حديث توفرت فيه شروط الصحة |
| **الحديث الحسن** | حديث دون الصحيح في الرتبة |
| **الحديث الضعيف** | حديث لم تتوفر فيه شروط الصحة |
| **الكتب الستة** | صحيح البخاري، صحيح مسلم، وسنن الترمذي وأبي داود والنسائي وابن ماجه |
| **السورة** | فصل من فصول القرآن الكريم (114 سورة) |
| **التفسير** | علم بيان معاني القرآن الكريم |
| **التفسير الميسر** | تفسير مختصر يُفهم من عامة الناس |

| **دراسة** | سياق التعلم | علم، تعلم |

| **شكر** | سياق الامتنان | نعمة، حمد |
