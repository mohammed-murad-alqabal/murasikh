## 🧪 اختبارات الأمان المطلوبة

### اختبارات مؤتمتة (Automated Tests)

```bash
# 1. Python Security Linter
bandit -r app/ -f json -o security-report.json

# 2. Dependency Vulnerabilities
safety check -r requirements.txt --json > vulnerabilities.json

# 3. Container Scanning
trivy image murassikh/api:latest --output container-scan.json

# 4. OWASP ZAP Scan
zap-baseline.py -t https://api.murassikh.com -r zap-report.html
```
