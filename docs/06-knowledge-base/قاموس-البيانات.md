# 📚 قاموس البيانات (Data Dictionary)

دليل شامل لجميع أنواع البيانات والكائنات المستخدمة في نظام مُرَسِّخ.

---

## 🔠 أنواع البيانات الأساسية

### 1. الحالات العاطفية (Emotion Types)

```typescript
type EmotionType = 
  | 'غضب'      // Anger
  | 'حزن'      // Sadness  
  | 'قلق'      // Anxiety
  | 'فرح'      // Joy
  | 'طبيعي'    // Neutral
  | 'سفر'      // Travel
  | 'دراسة'    // Study
  | 'مرض'      // Illness
  | 'شكر';     // Gratitude
```

**وصف:** الحالات العاطفية الرئيسية التي يتعرف عليها النظام.

| الحالة | الوصف | الكلمات المفتاحية |
|--------|-------|-------------------|
| **غضب** | مشاعر الغضب والعصبية | غضب، عصبية، انفعال، حنق، غيظ |
| **حزن** | مشاعر الحزن والأسى | حزن، أسى، وجع، ألم، هم |
| **قلق** | مشاعر القلق والخوف | قلق، خوف، توتر، هم، خشية |
| **فرح** | مشاعر الفرح والسعادة | فرح، سرور، سعادة، بهجة |
| **سفر** | حالات السفر والترحال | سفر، رحلة، سير، انتقال |
| **دراسة** | حالات الدراسة والتعلم | علم، تعلم، قراءة، دراسة |
| **مرض** | حالات المرض والوعكة | مرض، ألم، وعكة، شفاء |
| **شكر** | مشاعر الشكر والحمد | شكر، حمد، نعمة، فضل |

### 2. مستويات الاستجابة (Tier Levels)

```typescript
type ResponseTier = 
  | 'minimal'    // المستوى الأول: رمز فقط
  | 'moderate'   // المستوى الثاني: نص مختصر  
  | 'full';      // المستوى الثالث: النص كاملاً مع التفسير
```

**وصف:** المستويات الثلاثة لنظام الاستجابة المدرجة.

| المستوى | الوصف | مثال | وقت العرض |
|---------|-------|------|-----------|
| **minimal** | رمز فقط لتجنب إزعاج المستخدم | 💚, 🌸, 🕊️ | فوري (< 500ms) |
| **moderate** | نص مختصر بدون تفسير | آية قصيرة | فوري (< 2s) |
| **full** | النص كاملاً مع التفسير | آية + تفسير ميسر | فوري (< 2s) |

### 3. أنواع المحتوى (Content Types)

```typescript
type ContentType = 
  | 'verse'     // آية قرآنية
  | 'hadith'    // حديث نبوي  
  | 'symbol';   // رمز بسيط
```

**وصف:** أنواع المحتوى التي يمكن للنظام تقديمها.

| النوع | الوصف | هيكل البيانات |
|-------|-------|---------------|
| **verse** | آية من القرآن الكريم | ```{surah, ayah, text, tafsir}``` |
| **hadith** | حديث من السنة النبوية | ```{collection, number, text, grade}``` |
| **symbol** | رمز بسيط للاستجابة المدرجة | ```{symbol, color, meaning}``` |

## 📊 كائنات البيانات الرئيسية

### 1. كائن المستخدم (User Object)

```typescript
interface User {
  id: number;                    // معرف المستخدم
  username: string | null;       // اسم المستخدم (اختياري)
  email: string;                 // البريد الإلكتروني
  preferences: UserPreferences;  // التفضيلات
  is_active: boolean;            // نشط/غير نشط
  created_at: string;            // تاريخ الإنشاء
  updated_at: string;            // تاريخ التحديث
  is_deleted: boolean;           // محذوف/غير محذوف
}

interface UserPreferences {
  notification_style: ResponseTier;  // أسلوب الإشعارات
  language: 'ar' | 'en';             // اللغة المفضلة
  theme: 'light' | 'dark';           // الثيم
  font_size: 'small' | 'medium' | 'large'; // حجم الخط
  daily_reminders: boolean;          // تذكيرات يومية
  sound_enabled: boolean;            // تفعيل الصوت
  vibration_enabled: boolean;        // تفعيل الاهتزاز
}
```

### 2. كطلب التوصية (Recommendation Request)

```typescript
interface RecommendationRequest {
  text: string;                    // نص المستخدم (مطلوب)
  emotion_hint?: EmotionType;      // تلميح الحالة العاطفية (اختياري)
  user_id?: number;                // معرف المستخدم (اختياري)
  language?: 'ar' | 'en';          // اللغة (اختياري)
  metadata?: RequestMetadata;      // بيانات وصفية (اختياري)
}

interface RequestMetadata {
  device_type?: 'mobile' | 'tablet' | 'web';  // نوع الجهاز
  app_version?: string;                       // إصدار التطبيق
  timestamp?: string;                         // الطابع الزمني
  location?: { lat: number; lng: number };    // الموقع (اختياري)
}
```

**قواعد التحقق:**
- `text`: مطلوب، طوله 3-2000 حرف
- `emotion_hint`: إذا تم توفيره، يجب أن يكون من `EmotionType`
- `user_id`: إذا تم توفيره، يجب أن يكون رقمياً موجباً

### 3. كائن تحليل المشاعر (Emotion Analysis)

```typescript
interface EmotionAnalysis {
  emotion: EmotionType;           // الحالة العاطفية المكتشفة
  confidence: number;             // ثقة التحليل (0.0 - 1.0)
  intensity: 'low' | 'medium' | 'high';  // شدة المشاعر
  keywords: string[];             // الكلمات المفتاحية المستخرجة
  alternatives?: AlternativeEmotion[]; // بدائل محتملة
}

interface AlternativeEmotion {
  emotion: EmotionType;           // حالة عاطفية بديلة
  confidence: number;             // ثقة البديل
  reason: string;                 // سبب الاقتراح
}
```

**مثال:**
```json
{
  "emotion": "قلق",
  "confidence": 0.82,
  "intensity": "medium",
  "keywords": ["قلق", "مستقبل", "توتر"],
  "alternatives": [
    {
      "emotion": "حزن",
      "confidence": 0.15,
      "reason": "احتوى النص على كلمات تدل على الحزن"
    }
  ]
}
```

### 4. كائن التوصية (Recommendation)

```typescript
interface Recommendation {
  type: ContentType;              // نوع المحتوى
  content: Verse | Hadith | Symbol; // المحتوى الفعلي
  tier: ResponseTier;             // مستوى الاستجابة
  relevance: number;              // ارتباط المحتوى بالاستعلام (0.0-1.0)
  source_verified: boolean;       // تم التحقق من المصدر
  timestamp: string;              // وقت إنشاء التوصية
  metadata: RecommendationMetadata; // بيانات وصفية
}

interface Verse {
  id: number;                     // معرف الآية
  surah_number: number;           // رقم السورة (1-114)
  ayah_number: number;            // رقم الآية
  arabic_text: string;            // النص العربي
  uthmani_text?: string;          // نص عثماني (اختياري)
  translation: string;            // الترجمة
  tafsir: string;                 // التفسير
  tafsir_source: 'ibn_kathir' | 'saadi' | 'muyassar'; // مصدر التفسير
  tags: string[];                 // الوسوم
}

interface Hadith {
  id: number;                     // معرف الحديث
  collection: 'bukhari' | 'muslim' | 'tirmidhi' | 'abudawud' | 'nasai' | 'ibnmajah';
  hadith_number: string;          // رقم الحديث
  arabic_text: string;            // النص العربي
  translation: string;            // الترجمة
  explanation: string;            // الشرح
  narrator?: string;              // الراوي (اختياري)
  grade: 'sahih' | 'hasan' | 'daif'; // درجة الصحة
  tags: string[];                 // الوسوم
}

interface Symbol {
  symbol: string;                 // الرمز (emoji)
  color: string;                  // اللون (hex code)
  meaning: string;                // المعنى
  arabic_label: string;           // التسمية العربية
}

interface RecommendationMetadata {
  processing_time_ms: number;     // وقت المعالجة
  cache_hit: boolean;             // هل كان من الكاش؟
  model_used: string;             // النموذج المستخدم
  confidence_threshold: number;   // حد الثقة المستخدم
}
```

### 5. كائن التفاعل (Interaction)

```typescript
interface Interaction {

  response_delayed: boolean;      // هل تم تأجيل الرد؟

interface Feedback {
  rating: 'positive' | 'negative' | 'neutral'; // التقييم

```

## 📈 أنواع الاستجابة من API

### 1. استجابة نجاح (Success Response)

```typescript
interface SuccessResponse<T> {
  success: true;
  data: T;
  meta: ResponseMetadata;
}

interface ResponseMetadata {
  response_time_ms: number;       // وقت الاستجابة
  from_cache: boolean;            // هل كان من الكاش؟
  request_id: string;             // معرف الطلب
  timestamp: string;              // الطابع الزمني
}
```

**مثال:**
```json
{
  "success": true,
  "data": {
    "interaction_id": 12345,
    "emotion": { ... },
    "recommendation": { ... }
  },
  "meta": {
    "response_time_ms": 1850,
    "from_cache": false,
    "request_id": "req_abc123",
    "timestamp": "2026-09-11T10:00:00Z"
  }
}
```

### 2. استجابة خطأ (Error Response)

```typescript
interface ErrorResponse {
  success: false;
  error: {
    code: string;                 // كود الخطأ
    message: string;              // رسالة الخطأ
    details?: any;                // تفاصيل إضافية (اختياري)
    request_id?: string;          // معرف الطلب (اختياري)
  };
}
```

**أكواد الأخطاء الشائعة:**

| الكود | الرسالة | الوصف |
|-------|---------|-------|
| `EMPTY_TEXT` | "النص المدخل فارغ" | لم يتم إدخال نص |
| `TEXT_TOO_SHORT` | "النص يجب أن يكون على الأقل 3 أحرف" | النص قصير جداً |
| `TEXT_TOO_LONG` | "النص يجب أن لا يتجاوز 2000 حرف" | النص طويل جداً |
| `INVALID_EMOTION` | "الحالة العاطفية غير صالحة" | `emotion_hint` غير صالح |
| `AI_SERVICE_UNAVAILABLE` | "خدمة الذكاء الاصطناعي غير متاحة حالياً" | Gemini API غير متاح |
| `DATABASE_ERROR` | "خطأ في قاعدة البيانات" | خطأ في PostgreSQL |
| `RATE_LIMIT_EXCEEDED` | "تم تجاوز حد الطلبات المسموح به" | Rate limiting |
| `INTERNAL_SERVER_ERROR` | "خطأ داخلي في الخادم" | خطأ غير متوقع |

**مثال:**
```json
{
  "success": false,
  "error": {
    "code": "EMPTY_TEXT",
    "message": "النص المدخل فارغ",
    "request_id": "req_abc123"
  }
}
```

### 3. استجابة Cache Hit

```typescript
interface CacheHitResponse<T> extends SuccessResponse<T> {
  meta: ResponseMetadata & {
    from_cache: true;
    cache_key: string;
    cache_ttl_remaining: number;  // الوقت المتبقي للكاش (ثواني)
  };
}
```

**مثال:**
```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "response_time_ms": 85,
    "from_cache": true,
    "cache_key": "rec:قلق",
    "cache_ttl_remaining": 86340,
    "request_id": "req_def456",
    "timestamp": "2026-09-11T10:00:00Z"
  }
}
```

## 🗂️ هيكل البيانات في Vector DB

### 1. متجه Embedding (Embedding Vector)

```typescript
type EmbeddingVector = number[];  // 768 رقم عائم
```

**خصائص:**
- الطول: 768 (بُعد GATE-AraBERT-v1)
- القيم: أرقام عائمة بين -1 و 1
- التطبيع: L2 normalized

### 2. وثيقة Vector DB (Vector Document)

```typescript
interface VectorDocument {
  id: string;                     // المعرف (مثال: "verse_3_134")
  embedding: EmbeddingVector;     // المتجه
  document: string;               // النص العربي
  metadata: VectorMetadata;       // البيانات الوصفية
}

interface VectorMetadata {
  type: 'verse' | 'hadith';       // النوع
  source_id: number;              // المعرف في قاعدة البيانات
  emotion: EmotionType;           // الحالة العاطفية
  tags: string[];                 // الوسوم
  language: 'ar';                 // اللغة
  created_at: string;             // تاريخ الإنشاء
}
```

**مثال:**
```json
{
  "id": "verse_3_134",
  "embedding": [0.123, -0.456, 0.789, ...],
  "document": "وَالْكَاظِمِينَ الْغَيْظَ",
  "metadata": {
    "type": "verse",
    "source_id": 134,
    "emotion": "غضب",
    "tags": ["غضب", "صبر", "كظم"],
    "language": "ar",
    "created_at": "2026-09-11T00:00:00Z"
  }
}
```

interface SearchResult {

## 📝 قواعد التسمية (Naming Conventions)

### 1. تسمية المتغيرات:

| النوع | التنسيق | مثال |
|-------|---------|------|
| Tables | snake_case | `user_interactions` |
| Columns | snake_case | `created_at` |
| API Endpoints | kebab-case | `/api/v1/recommend` |
| JSON Fields | camelCase | `responseTimeMs` |
| Python Variables | snake_case | `user_id` |
| Dart Variables | camelCase | `userId` |

### 2. تسمية الكاش:

| النوع | التنسيق | مثال |
|-------|---------|------|
| Recommendation Cache | `rec:{emotion}` | `rec:قلق` |
| User Cache | `user:{id}` | `user:123` |
| Verse Cache | `verse:{id}` | `verse:134` |
| Rate Limit | `rate:{ip}:{endpoint}` | `rate:192.168.1.1:/recommend` |

### 3. تسمية الملفات:

| النوع | التنسيق | مثال |
|-------|---------|------|
| Python Files | snake_case | `emotion_analyzer.py` |
| Dart Files | snake_case | `recommendation_service.dart` |
| Markdown Files | kebab-case | `data-dictionary.md` |
| SQL Files | snake_case | `create_tables.sql` |
