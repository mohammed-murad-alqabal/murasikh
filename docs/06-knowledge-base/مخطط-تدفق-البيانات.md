## 🗂️ مخطط البيانات المخزنة

### Redis Cache Structure

```
Redis Key Pattern: rec:{emotion}
TTL: 86400 seconds (24 hours)

Example:
  Key: rec:قلق
  Value: {
    "emotion": "قلق",
    "confidence": 0.82,
    "recommendation": {
      "type": "verse",
      "arabic_text": "أَلَا بِذِكْرِ اللَّهِ تَطْمَئِنُّ الْقُلُوبُ",
      "source": "سورة الرعد: 28"
    }
  }
```
