### الأخطاء والتعامل معها:

| الخطأ | الكود | الإجراء | المستخدم يرى |
|-------|-------|--------|-------------|
| **Gemini API غير متاح** | 503 | استخدام تحليل مبسط | توصية عامة + تحذير خفيف |
| **قاعدة البيانات Down** | 503 | استخدام Memory Cache | توصية + لا حفظ للسجل |
| **Redis Cache Down** | 503 | تخطي Cache | أبطأ قليلاً |
| **ChromaDB غير متاح** | 503 | استخدام بحث نصي | دقة أقل |
| **نص قصير جداً** | 400 | رفض الطلب | رسالة إرشاد |
| **نص فارغ** | 400 | رفض الطلب | طلب إدخال نص |
| **Rate Limit** | 429 | رفض الطلب | حاول لاحقاً |
