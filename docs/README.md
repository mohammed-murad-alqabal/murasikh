## 🎯 عن المشروع

**مُرَسِّخ** هو MVP تجريبي لتوصية قرآنية نصية مخصصة. الصوت وتحليل الوجه قدرات تجريبية محدودة، والحديث خارج عقد التوصية الحالي.

**الرؤية:** ترسيخ القيم الإسلامية وتعزيز السلام الداخلي من خلال مرافق رقمي ذكي.
