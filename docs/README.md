# 📚 مركز توثيق مشروع مُرَسِّخ

> **الرفيق الروحي الذكي** - نظام ذكاء اصطناعي لتقديم توجيه ديني وروحي لحظي أو مؤجل

---

## 🎯 عن المشروع

**مُرَسِّخ** هو نظام ذكاء اصطناعي متقدم يرافق المستخدم في حياته اليومية، يعمل على تحليل السياق (الصوت، الصورة، المشاعر) لتقديم توجيه ديني وروحي يعتمد على القرآن الكريم والسنة النبوية.

**الرؤية:** ترسيخ القيم الإسلامية وتعزيز السلام الداخلي من خلال مرافق رقمي ذكي.
