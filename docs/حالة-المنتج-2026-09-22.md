# حالة المنتج الرسمية — مُرَسِّخ

**تاريخ الاعتماد:** 2026-09-22
**النسخة المرجعية:** `de865e042e53bdc3a3f4686bfd6cff76dad5d960`
**التصنيف الحالي:** MVP تجريبي / مرشح لـstaging، وليس إصداراً تجارياً.

تستخدم هذه الوثيقة مرجعاً واحداً لحالة الميزات. لا تعني عبارة «منفذ» أن الميزة مثبتة إنتاجياً؛ لذلك تميز المصفوفة بين التنفيذ البرمجي والدليل التشغيلي.

|---|---|---|---|---|
| التوصية القرآنية النصية | منفذة ومثبتة في CI | FastAPI + RAG + Chroma + Gemini مع fallback | اختبارات Backend وCI وفحص بيانات القرآن | تثبيت قياس الملاءمة العربية وسياسة المحتوى |
| عقد التوصية | قيد التوحيد | المسار الرسمي `/api/v1/analyze` | اختبارات عقد Backend | تحديث كل وثائق API وFlutter وإضافة contract guard |
| Home والآية السياقية | منفذة ومثبتة في CI | `POST /api/v1/home/verse` | اختبارات Home وCI | منع المسارات القديمة وتوثيق fallback |
| المصادقة والتاريخ | منفذة ومثبتة في CI | JWT وrefresh rotation وعزل `user_id` | اختبارات Auth والعزل | اختبار جهاز وتدفق حذف الحساب |
| الصوت | تجريبية | تحليل نبرة heuristic ورفع محمي | اختبارات API وفحص magic bytes | توثيق أنها ليست ASR وإضافة حدود مدة وتوازي |
| العمل دون اتصال | منفذة جزئياً | cache وfallback وpending feedback | اختبارات Offline | لا يوجد تحليل محلي كامل؛ يجب تخفيف الوعد أو بناء محرك محلي |
| الخصوصية المحلية | منفذة جزئياً | secure storage للرموز وHive للبيانات | قراءة الكود واختبارات محدودة | تشفير Hive وإثبات الحذف وsnapshot privacy |

## قرار النطاق والمحتوى

النطاق التشغيلي الحالي هو **توصية قرآنية**. لا تعد خدمات الأحاديث أو ملفاتها جزءاً من عقد التوصية الحالي، ولا يجوز إدخال محتوى غير `type=verse` إلى Collection القرآن. أي توسع لاحق إلى الأحاديث يحتاج مصدراً canonical وإصداراً ودرجة توثيق واختبارات مستقلة.

## قرار الإطلاق

يمكن استخدام النسخة الحالية للتطوير والاختبار وstaging المشروط. لا يجوز وصفها بأنها «100% مكتملة» أو «جاهزة للإطلاق التجاري» قبل إغلاق عقد API، واختبار الخصوصية والحذف، وstaging smoke، وrestore drill، والقياس، واختبارات الأجهزة.
