# نطاق المنتج الحالي — Murasikh

**حالة الوثيقة:** Current / Source of Truth للنطاق التشغيلي
**تاريخ الاعتماد:** 2026-09-25
**الإصدار:** MVP-0.1
**نطاق هذه الوثيقة:** ما يجوز عرضه أو اختباره في النسخة الحالية، وليس الرؤية طويلة الأجل.

## القرار المختصر

Murasikh في هذه المرحلة هو:

> **توصية قرآنية نصية مخصصة** من رسالة المستخدم، مع Home سياقي، سجل ومصادقة، وتخزين محلي مشفّر. الصوت وتحليل الوجه قدرات تجريبية محدودة، والعمل دون اتصال يعرض cache/fallback موسوماً ولا ينفذ تحليلاً محلياً كاملاً.

## القدرات الحالية

| القدرة | الحالة المسموح بإعلانها | الحدود الحالية | دليل القبول |
|---|---|---|---|
| التوصية القرآنية النصية | MVP أساسي | القرآن فقط؛ لا ادعاء بفهم نفسي أو علاجي | `POST /api/v1/analyze`، اختبارات API/RAG، Quran manifest |
| Home والآية السياقية | MVP أساسي | إشارات سياقية محدودة؛ fallback يجب أن يكون canonical | `POST /api/v1/home/verse` واختبارات العقد |
| المصادقة والسجل | MVP أساسي | session revocation وحذف الحساب يجب أن ينجحا قبل staging | auth/history tests وE2E |
| الصوت | Prototype | تحليل نبرة/خصائص صوتية؛ ليس ASR أو فهماً للكلام | upload/codec/device tests |
| الوجه والسياق الحيوي | Prototype اختياري | لا تشخيص ولا استنتاج نفسي؛ لا إرسال دون موافقة وتقليل | consent/privacy tests |
| Offline | Partially Implemented | cache وfallback وfeedback queue فقط؛ كل نتيجة تحمل source/status | offline/widget tests |
| الحديث ومصادر دينية إضافية | Deferred | خارج عقد التوصية الحالي | قرار جديد مستقل مع provenance ومراجعة |
| التعلم الذاتي وRL وWearables وMicroservices | Deferred | لا تدخل MVP قبل قياسات واحتياج مثبت | ADR وcapacity/evaluation evidence |

## ما لا يجوز ادعاؤه

- لا يجوز وصف النسخة بأنها Production Ready أو Verified end-to-end.
- لا يجوز وصف تحليل الصوت بأنه Speech-to-Text أو فهم دلالي.
- لا يجوز وصف إشارات الوجه أو الضغط بأنها تشخيص أو قياس نفسي.
- لا يجوز وصف Offline بأنه AI محلي كامل أو معالجة جديدة بلا شبكة.
- لا يجوز وصف feedback بأنه تدريب أو تعلم ذاتي قبل موافقة وحوكمة وتقييم.
- لا يجوز إدخال الحديث إلى مسار Quran-only أو إظهاره كأنه جزء من التوصية.

## مصادر الحقيقة

1. هذه الوثيقة هي مصدر الحقيقة للنطاق والـclaims الحالية.
2. `docs/حالة-المنتج-2026-09-22.md` مصدر حالة التنفيذ والأدلة المرتبطة بالـcommit.
3. OpenAPI المولد من FastAPI هو مصدر حقيقة المسارات والـschemas؛ `docs/03-api/العقد-المعتمد.md` واجهة بشرية مشتقة منه.
4. الكود واختبارات CI الناجحة ونتائج staging/device/restore المرتبطة بالـcommit هي الدليل، لا وجود الوثيقة أو الاختبار وحده.

## قواعد تغيير النطاق

أي إضافة إلى capability الحالية تتطلب تحديثاً متزامناً لـ:

- هذا الملف ومصفوفة حالة المنتج.
- عقد API وOpenAPI وعميل Flutter.
- سياسة الخصوصية ونسخ البيانات والحذف.
- اختبارات العقد والفشل والبيانات العربية عند الحاجة.
- معايير قبول ونتيجة CI مرتبطة بـcommit وبيئة.

الوثائق القديمة تبقى مرجعاً تاريخياً، ويجب وسمها `Historical` أو `Planned` بدلاً من عرضها كحالة حالية.
